FlatRadar watches seven Dutch housing platforms, sends you new listings that match your filters, and can book Holland2Stay homes and apply on Plaza for you.

Getting started

Use flatradar.app

Open flatradar.app. You can browse every listing without an account. To get alerts, choose Sign in / Register: a new username creates an account. You land in Account settings, where you set your filters and how you want to be notified.

iOS and Android apps

iOS: App Store. Android: download the .apk. Sign in with the same account and allow notifications; the app receives push alerts without any further setup.

Run your own copy

FlatRadar is free for personal, non-commercial use. A copy you run yourself shows Self-hosted next to its name; you are responsible for running it.

Docker (recommended for a VPS):

cp .env.example .env && mkdir -p data logs logs/caddy
# Caddyfile: replace your.domain.com with your domain
# .env: set WEB_PASSWORD, PUBLIC_BASE_URL and SESSION_COOKIE_SECURE=true
docker compose up -d

Open https://your.domain.com, sign in as admin, then go to Administration → System Info and choose Start monitor. Deployment, email and proxy settings are in the project documentation.

To try it locally without a domain: docker compose -f docker-compose.yml -f docker-compose.local.yml up -d h2s, then open http://127.0.0.1:8088. This mode has no HTTPS or sign-in and is for your own machine only.

macOS / Windows: download the .dmg or .zip from Releases and run it; the browser opens automatically.

From source:

pip install -r requirements.txt
python -m cloakbrowser install
cp .env.example .env
python web.py      # web panel
python monitor.py  # monitoring loop, in a separate terminal

The panel and the monitor are separate processes. Running only the panel will not fetch listings.

The inbox

The home page is a housing inbox: a sidebar on the left, the list in the middle, and the selected listing on the right. On a phone, the menu button at the top left opens the sidebar.

  • My matches / All listings — the switch at the top of the sidebar. My matches uses your saved filters; All listings shows everything, and listings that match your filters carry a Match label.
  • Available to book, Unread listings and one entry per platform narrow the list. Opening a listing marks it read.
  • Search looks in listing names, cities and platforms. Edit filters next to the title takes you to your filters (or, when browsing without an account, applies a temporary filter).
  • The detail panel shows the price, status, facts about the home and a link to the Original listing. Always check the platform before acting.

An Inferred label means FlatRadar estimated the status instead of reading it from the platform. When a listing disappears from a fully checked feed, it becomes Reserved after 30 minutes and Occupied after 2 hours by default. An incomplete scrape never leads to that inference, and the label clears if the listing comes back.

List, Calendar and Map

The tabs above the list show the same listings three ways. Calendar places them by move-in date; listings without a confirmed date are listed separately. Map shows prices for single homes and counts for buildings with several; choose a marker to see its listings. The map only shows listings still seen recently (14 days by default) and offers an all-records view. Coordinates are worked out by the monitor, so new listings usually appear on the map within half an hour.

Statistics

Charts for the last 7, 30 or 90 days: new listings, status changes, cities, platforms, statuses and rent. They follow the sidebar: My matches counts only your matches, All listings counts everything.

Notifications

Go to Account settings → Notifications. The Notifications switch at the top governs every channel, app push included: with it off, nothing is sent at all. Then turn on at least one way to receive alerts.

App push

Sign in to the iOS or Android app with your account and allow notifications. That is all; the app also turns the Notifications switch on for you. Alerts follow your phone's language.

Telegram

  1. Create a bot with @BotFather and copy its token.
  2. Send any message to your new bot.
  3. Open https://api.telegram.org/bot<TOKEN>/getUpdates to find your chat ID.
  4. Enter the bot token and chat ID under Telegram.

Email

Sent by FlatRadar (default): enter your address and click the link in the confirmation email. Nothing is delivered until the address is confirmed, so nobody can sign up someone else's inbox. A self-hosted copy needs its administrator to set up the shared email service first; otherwise use your own SMTP server.

Your own SMTP server (administrators): switch the email mode to custom and enter the server details. With two-factor sign-in, use an app password.

WhatsApp and iMessage

WhatsApp goes through a paid Twilio account: Account SID, auth token and whatsapp:+… numbers. iMessage only works when FlatRadar itself runs on a Mac signed in to Messages.

Use Send Test Notification to check every channel, app push included; the result is listed per channel. While your account cannot receive anything, Account settings shows a short checklist naming the step that is missing.

Their listings show the building's service-cost range under the price, and notifications carry the same note. Leave some headroom in Max rent for those two, or filter them separately by platform.

Auto-booking and applications

Administrators set this up per user under Administration → Users → the user → Auto-booking. It needs notifications to be on with at least one working channel. Booking filters are separate from notification filters.

Holland2Stay

When a matching listing becomes Available to book, FlatRadar signs in to the user's Holland2Stay account, reserves the home, places the order and sends a payment link straight away. It never pays: payment is done by hand through that link.

If the outcome is uncertain, auto-booking pauses for that account. Check the orders on Holland2Stay, pay or cancel as needed, then choose Checked; resume auto-booking in the user's settings.

Plaza

FlatRadar can submit applications for matching Plaza listings. Enter the Plaza username and password and turn on automatic applications, which are off by default. An application takes effect immediately. If its outcome is uncertain, only that account and listing pause until you check it on Plaza and choose Checked; resume applications for this listing.

Applicant profile

Xior and OurDomain share one applicant profile (name, nationality, address, study, screening questions and ID document). Each group shows how many required fields are still missing. Screening answers must come from the applicant.

Start with Dry run. It checks the steps before submission without placing an order or application. It does not guarantee a real submission will succeed. Turn it off only when you are ready for real orders.

Administration

On a copy you run yourself, the admin account sees Administration in the sidebar:

  • Users — every account, its channels and signed-in apps; edit, reorder, test notifications.
  • Announcements — send a message to every user with notifications on.
  • Settings — polling, peak hours, platforms, cities and buildings. Saving asks the monitor to reload; the page shows whether it was applied and which values the environment overrides.
  • Client Management — app sessions and push devices; revoke or disable them.
  • Data Health, Log Viewer, Crash Reports and System Info — scraping health per platform, logs with search and levels, app crash reports, and starting or restarting the monitor.

Troubleshooting

No listings appear

  • The monitor is running: Administration → System Info. If it does not start, check the Log Viewer or docker compose logs h2s.
  • The platform is enabled and its cities or buildings are selected in Settings.
  • Data Health shows, per platform, when it last succeeded and why it is failing.

Notifications do not arrive

Open Account settings. While your account cannot receive anything, a checklist there names the missing step; if it is gone, the chain is complete. To check by hand:

  • The account is active and the Notifications switch is on.
  • There is at least one way to receive alerts: a channel with valid details, or a phone signed in to the app.
  • With email sent by FlatRadar, the address is confirmed.
  • Send Test Notification shows the result per channel.

Blocked with 403

Platforms behind Cloudflare sometimes block requests. Check the log for which platform and which error it is (not every 403 has the same cause), check the network and any proxy, then give the platform time to cool down. The deployment documentation explains proxy settings.

# FlatRadar Web 第一阶段原型 C

该原型以现有界面为视觉基准，用于评审首页与房源列表的视觉层级、响应式布局和基础交互。所有房源、数量、
时间及监控状态均为合成示例；原型不连接数据库或监控服务，也不会提交预订。

在项目根目录运行：

```bash
python -m http.server 19565 --bind 127.0.0.1 --directory prototypes/web-v21-solid
```

然后访问 `http://127.0.0.1:19565/`。原型支持首页与房源页切换、示例筛选及空结果、
中英文、浅色与暗色主题，以及手机导航。首页顶部的状态选择器用于预览监控暂停和预订
待核实的展示方式；选择器不影响真实监控。

这是设计验证而非正式应用：日历、地图、统计和设置仅为导航示意；原型未覆盖生产页面的
全部字段、权限和操作。后续实现需要重新接入现有数据、保留业务逻辑，并完成完整的
无障碍、响应式和行为测试。

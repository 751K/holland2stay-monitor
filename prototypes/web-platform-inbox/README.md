# 桌面个人房源收件箱原型

本原型采用平台导航、房源列表和详情三栏布局。登录演示身份默认进入“我的房源”，
基础范围由个人筛选条件决定。切换平台、查看可预订房源和搜索会进一步缩小当前范围。
平台数字统计符合基础条件的样本，不受当前平台选择或搜索影响，也不表示未读数。

房源数据来自服务器只读抽取的 21 条公开房源字段快照，包含七个平台各三条记录。
快照不能代表全量房源、实时可用性或监控状态。默认个人演示条件为全荷兰、租金不高于
€1,500、面积不小于 20 m²，匹配其中 16 条样本；这些条件不来自真实用户配置。
快照还包含从同一批房源只读补录的公开特征与最后出现时间，供正式后端的本地详情
验证使用。基础字段和特征的采样时间分别记录于 `capturedAt` 与 `featuresCapturedAt`。

筛选编辑器支持城市、最低及最高租金、最小面积和关注平台。用户可以取消修改、清除
草稿条件或保存并应用。价格解析按本快照的荷兰数字格式处理；显示保留来源价格原文。
在设置相应数值条件时，缺少价格或面积的记录不计入匹配结果。城市选项根据本快照的
城市文字归并，不代表正式地理数据服务。

顶部提供游客、正常用户和管理员三个身份的预览：

- 游客使用独立的临时条件；“登录 / 注册”仅提供演示身份切换，并将当前临时条件和
  搜索带入个人收件箱，不执行真实认证，也不会自动持久化这次带入的条件。
- 正常用户可以将个人演示条件保存到当前浏览器的 `flatradar-personal-inbox-demo-v1`
  存储项；刷新后恢复。若浏览器禁止保存，界面明确显示条件仅在本次有效。
- 管理员保留个人账号与收件箱，通过“管理后台”进入独立工作区，并可以返回房源。
  管理模块只展示导航与功能范围，没有读取或修改管理数据。

筛选与通知共用基础条件是设计方向，原型不会发送通知。列表筛选与详情可操作；日历、
地图、统计、账号、外观、语言、帮助、条款及其他入口仍为功能说明，没有连接正式接口。
所有身份变化和条件保存均只影响本地原型，不修改服务器上的用户、权限或运行配置。
